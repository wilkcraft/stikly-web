What is Stikly?

Stikly turns your desktop into a real bulletin board. Each note is its own small window—without borders or a Windows title bar—so you can have as many as you like, in any color you choose, pinned wherever you want.

Everything is saved on your own computer. Every note is its own small file, and a built-in panel lets you browse, search and reopen all of them whenever you want.

Each note, your way

The bottom bar of each note has just what you need to write quickly and without distractions.

Formatted text

Bold, italics, underline and strikethrough are right inside the note. The A button changes the color of the selected text and the marker button highlights it, just like a real highlighter. Right-click either one to remove the color. Your selection stays put while you try different colors.

Lists & checklists

Bulleted and numbered lists, plus checklists: click a box and the whole line is crossed out. Click again to undo it.

Move and Resize

Drag the note by its top bar or stretch a corner to enlarge it. Stikly remembers the position and size of each note between sessions.

All the ones you need

The + button creates a new note slightly offset from the previous one, so they never stack directly on top of each other.

All your notes in one panel

When Stikly starts, or when you press Ctrl+O, a panel shows every saved note as a real sticky note, with its colors, lists and highlights. Search, open, import or delete from there.

Auto-save on exit

Use Close all notes from the tray icon (or just quit Stikly) and every note with text is saved automatically, named after its first line.

Three ways to pin a note

The three-dot menu hides Stikly's most particular trick: choosing which layer of your desktop each note lives in. Try it below.

What's behind each note

On the inside, Stikly is an Electron app with a somewhat unusual piece: it communicates directly with the Windows API to switch layers of a window.

main.js — the brain

The main process of Electron. Creates the window for each note, saves every note as its own .json file in a notes folder, opens the notes panel, and controls the system tray icon.

preload.js — the bridge

Exposes only a few safe functions to the note —create, delete, update, save, open— through contextBridge, without giving it direct access to Node.js. The notes panel has its own bridge too.

note.html / note.js / note.css — what you see

The interface where you write: the text area, the format bar and the color and position menus.

library.html / .js / .css — the panel

The window that lists your saved notes. It rebuilds each note's formatting from its saved HTML through a strict sanitizer, so previews look real but can never run code.

windows-window.ps1 + .cs — the translator

A PowerShell script that compiles a small piece of C# at runtime and calls Windows API functions directly —SetParent, SetWindowPos— to move the window from one layer to another.

your desktop, your data

Every note is saved as its own .json file inside a notes folder in the application's data folder on your own computer (%APPDATA%\stikly\notes). Notes are written when you press Save, when you close one that was already saved, and when you quit Stikly or choose "Close all notes" — in that case every note with text is saved automatically, named after its first line. Closing a never-saved note with its own × button discards it. Stikly does not send anything to any server; to back up your data, just copy that folder.
